# Tacview Realtime Recorder

Standalone package to read a .ACMI file and host a single client
Tacview Real Time Telemetry stream.

Reimplementation of [Open Radar's AcmiFiletoStream.py](https://github.com/UOAF/OpenRadar/blob/main/scripts/AcmiFiletoStream.py).

Uses the public [Tacview Realtime Telemetry Protocol](https://raia-software-inc.gitbook.io/tacview/technical-documentation/real-time-telemetry-public-protocol).
